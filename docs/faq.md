## 安装与打开

### macOS 提示“无法验证开发者”或“Apple 无法检查其是否包含恶意软件”

当前版本使用 ad-hoc 签名，还没有做 Apple 公证，所以首次打开时会被系统拦截。

1. 先把 `LAN Share.app` 拖到“应用程序”文件夹。这样做也是安全上的要求，原因见 [SECURITY.md](../SECURITY.md#已知限制)。
2. 双击打开一次，在弹窗中点击“完成”或“取消”。
3. 打开“系统设置 → 隐私与安全性”，在页面底部找到 LAN Share，点击“仍要打开”，然后输入 Mac 登录密码确认。

macOS 14 及更早的版本也可以在 Finder 中按住 Control 点按应用，选择“打开”。

### Windows 提示“Windows 已保护你的电脑”

Windows 包还没有做代码签名，SmartScreen 会拦截。点击“更多信息 → 仍要运行”即可。

### Linux 双击没有反应

请在终端运行 `./lan-share` 查看错误。图形界面需要 GTK 3。在 Debian/Ubuntu 上可以安装 `libgtk-3-0`，“记住密码”还需要 `libsecret-1-0` 和正在运行的密钥环服务（如 GNOME Keyring）。

## 启动共享

### 提示“445 端口已被占用”

445 是 SMB 的标准端口，同一时间只能被一个程序使用。

- **macOS**：多半是系统的文件共享开着。打开“系统设置 → 通用 → 共享”，关闭“文件共享”后重试。在终端运行下面的命令可以查看占用 445 的进程：

  ```sh
  sudo lsof -nP -iTCP:445 -sTCP:LISTEN
  ```

- **Windows**：系统自带的文件共享（Server 服务）默认就占用 445。查看占用情况：

  ```bat
  netstat -ano | findstr :445
  ```

  要让 LAN Share 使用 445，需要停用 Server 服务并重启电脑，这会同时关闭这台电脑的 Windows 文件和打印机共享。Windows 版尚未经过完整的真机验收，请自行评估后再操作。

- **Linux**：一般是 Samba。查看并按需停止：

  ```sh
  sudo ss -ltnp 'sport = :445'
  sudo systemctl stop smbd
  ```

### macOS 弹出管理员授权窗口，应该输入什么？

输入这台 Mac 的管理员账户密码。它只用于授权端口助手绑定 445 端口，和投影仪上填写的 SMB 密码无关。端口助手绑定完端口后立即退出，不会安装常驻服务。

### Linux 提示“监听 445 需要系统端口授权”

普通用户默认不能监听 1024 以下的端口。可以给程序授予绑定低端口的能力：

```sh
sudo setcap 'cap_net_bind_service=+ep' ./lan-share
```

替换或更新程序文件后需要重新执行一次。目前还没有提供 Linux 授权安装器。

## 投影仪连接

### 应用里显示“未找到局域网地址”

应用只列出私有网段的 IPv4 地址（如 `192.168.x.x`、`10.x.x.x`），并会过滤 VPN 和虚拟网卡。请确认电脑已经连上 Wi-Fi 或有线网络。切换网络后，停止并重新启动共享即可刷新地址。

### 投影仪找不到电脑，或连接超时

- 确认投影仪和电脑连在同一个路由器上，而不是一个连访客网络、一个连主网络。
- 有些路由器开启了“AP 隔离”或“客户端隔离”，同一 Wi-Fi 下的设备之间也无法互访，需要在路由器设置中关闭。
- 首次启动共享时，系统防火墙可能会询问是否允许传入连接，请选择允许。
- 目前需要手动输入地址，应用不会在网络上自动广播自己。请在投影仪的文件管理器中手动添加 SMB 服务器，填写应用显示的 IP 地址，端口填 445。

### 提示用户名或密码错误

- 用户名默认为 `projector`。密码区分大小写，可以点击眼睛图标核对。
- 没有开启“记住密码”时，每次打开应用都会生成新的随机密码，投影仪上保存的旧密码就失效了。
- 共享运行期间不能修改账号。要更换用户名或密码，请先停止共享，修改后再重新启动。

### 能登录，但看不到文件夹或文件列表为空

- 共享名固定为 `Media`。有些设备需要手动填写共享名或路径 `/Media`。
- macOS 上，如果共享的是“文稿”“下载”“桌面”或外置磁盘中的文件夹，系统可能会请求访问权限，请选择允许。之后也可以在“系统设置 → 隐私与安全性 → 文件与文件夹”中修改。
- 只会列出普通文件和文件夹。指向共享目录以外的符号链接会被隐藏。

### 设备只支持 SMB1

LAN Share 支持 SMB 2.0.2 到 3.1.1，不支持早已淘汰、并且存在安全问题的 SMB1。诊断日志中如果出现 `client_offered_only_SMB1`，就说明设备只提供了 SMB1。可以在设备设置中查找“SMB2”或“SMB 协议版本”选项，或者改用支持 SMB2 的播放器应用（如 Kodi、VLC）。

## 播放与使用

### 播放到一半中断

- 电脑休眠时共享也会中断。LAN Share 不会阻止系统休眠，播放期间请保持电脑唤醒，或在系统设置中暂时关闭自动休眠。
- 关闭应用窗口或点击“停止共享”都会立即断开所有连接。
- Wi-Fi 信号较弱时，高码率视频可能卡顿，可以尝试用有线网络或 5 GHz Wi-Fi。

### 能在投影仪上删除或上传文件吗？

不能。共享始终是只读的，所有写入、删除和重命名都会被拒绝，这是有意的设计。

### 为什么不能选择整个用户目录？

应用的配置和日志就在用户目录下。为了避免把它们也共享出去，不能选择包含应用配置目录的上层文件夹。请选择一个更具体的媒体文件夹。

### 共享的内容会被加密吗？

SMB 登录过程不会明文传输密码，但当前版本不支持 SMB 传输加密，文件内容在局域网中是未加密传输的。请只在可信的家庭或办公网络中使用。

## 密码与设置

### 提示“系统凭据存储不可用”

“记住密码”依赖系统的凭据存储：macOS 钥匙串、Windows 凭据管理器、Linux Secret Service。Linux 上如果没有运行密钥环服务，请安装并解锁 GNOME Keyring 等服务，或取消“记住密码”。

### 配置和日志保存在哪里？

| 系统 | 位置 |
| --- | --- |
| macOS | `~/Library/Application Support/LAN Share/` |
| Windows | `%AppData%\LAN Share\` |
| Linux | `~/.config/LAN Share/`（遵循 `XDG_CONFIG_HOME`） |

`settings.json` 只保存文件夹、用户名和是否记住密码，不保存密码本身。日志在 `logs/` 目录下，不记录密码、文件内容或文件名。

### 如何重置所有设置？

退出应用，删除上表中的 `LAN Share` 文件夹即可。已记住的密码保存在系统凭据存储中，名称为 `io.github.renyijiu.lanshare`，可以在钥匙串访问或凭据管理器中删除。
