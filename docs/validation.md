## 本次桌面版实测

2026-10-25，通过实际 GUI 选择目录、启动、观察连接数、停止。共享目录只包含专门准备的 MP4、SRT 和中文 TXT 三个测试文件。

客户端连接 本机局域网 IP 的 `445` 端口，协商为 SMB 3.0.2，完成认证、共享枚举、文件校验和随机读取。测试客户端运行在同一台 Mac，使用本机局域网 IP；这证明桌面服务的真实 445 启停与读文件流程，不代替另一台设备跨网络访问或投影仪实测。停止时保留一个正在读取的连接，验证其断开以及新连接失败。结束后没有留下 SMB 监听。

此前已用相同 SMB 库的命令行探针，在极米 NEW Z8X / Android 8.0.0 / 固件 5.0.0.30_375 (OY122V12.15.214) 的自带资源管理器确认画面、声音与拖动正常。这是协议兼容性的已有证据；本次桌面服务已通过本机测试，投影仪回归和备用授权路径仍需单独验收。

## 发布边界

当前为 0.x 预览版，macOS 使用 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证。当前支持单一只读共享 `Media`、单账号、手动 IP 连接；关闭窗口会停止共享，不包含托盘常驻、开机启动、网络自动发现或转码。

服务绑定 IPv4 的所有本机接口 `0.0.0.0:445`。界面列出的常见局域网地址仅供连接参考，不是接口访问限制；应用不会修改系统防火墙或路由器配置。
